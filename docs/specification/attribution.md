# Licença e Atribuição

O BCP é derivado em parte do Protocolo de Comércio Universal (UCP), licenciado
sob a licença Apache, versão 2.0.

## Proveniência

- Os esquemas JSON de linha de base derivam do release `2026-04-08` do UCP.
- O namespace `dev.ucp.*` foi renomeado para `br.dev.bcp.*`.
- A autoridade do esquema `ucp.dev` foi renomeada para `bcp.dev.br`.
- As extensões brasileiras e o manipulador Pix são adições originais do BCP.

## Avisos

- Licença completa: [`LICENSE`](site:LICENSE)
- Aviso de pacote: [`NOTICE`](site:NOTICE)
- Changelog de divergência: [`CHANGELOG-divergencia.md`](site:CHANGELOG-divergencia.md)

A documentação importada e as ferramentas de construção preservam os cabeçalhos Apache do UCP onde
presentes. As alterações do BCP são registradas em `NOTICE` e `CHANGELOG-divergencia.md`.
